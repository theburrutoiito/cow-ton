# 🐄 Cow-ton

Pure audio terrorism. A Web Audio API cow synthesizer designed to make your ears bleed.  

## 🚨 WARNING
**Turn down your volume before clicking! This is not a drill.**


## 🛠️ Features
* **Pure Synthesis:** No heavy `.mp3` files, the sound is synthesized from scratch using `sawtooth` waves directly in your browser.
* **Pure Pain:** Max volume nodes with unfiltered ear-splitting frequencies.
* **Chaotic Cows:** Fast clicking triggers a stampede of escaping cows.
  (btw I made this code using claude)
